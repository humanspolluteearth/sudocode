# Security

## Reporting a problem

If you find a security problem, **please do not open a public issue.** Email it to
[saysayeem.edu@gmail.com](mailto:saysayeem.edu@gmail.com) with the subject "Sudocode security".

Please include:

- What you found
- Steps to see it
- Which version or address you used (for example, the website or a local copy)

You can expect a first reply within about a week. This is a small volunteer project, so we cannot promise exact times. We will tell you when it is fixed, and thank you in public if you want that.

## What counts

Examples: a way to make Sudocode run code outside its sandbox, a way to read another person's saved files, or a way to inject a script through a program or a file.

A program that runs forever, or a wrong answer from the interpreter, is a normal bug. Please use the [bug report form](https://github.com/humanspolluteearth/sudocode/issues/new?template=bug_report.yml).

## Supported versions

Only the latest release, and the live website, are supported.

## Privacy

Sudocode has no accounts and does not track you. Your programs stay in your browser.
