Edexcel pseudocode reference

For Edexcel GCSE and International GCSE Computer Science. What the IDE accepts, written the way exam answers expect it. Keywords are in capitals. Every block is closed with END or UNTIL. Indent with four spaces.

1. Variables and I/O

SET score TO 0
SET name TO "Sam"
RECEIVE age FROM (INTEGER) KEYBOARD
SEND "Hello " & name TO DISPLAY
# everything after # is a comment

SET creates or updates a variable. Names are case-sensitive, so Score and score are different. RECEIVE takes one of INTEGER, REAL, STRING, BOOLEAN or CHARACTER. In the IDE, the console waits for you to type each value when RECEIVE runs.

2. Selection

IF mark >= 70 THEN
    SET grade TO "A"
ELSE
    IF mark >= 50 THEN
        SET grade TO "B"
    ELSE
        SET grade TO "C"
    END IF
END IF

ELSE is optional. There is no ELSE IF: for more than two outcomes, nest another IF inside ELSE. Each IF has its own END IF.

3. Iteration

Loop Form Notes
Count-controlled 
FOR i FROM 1 TO 10 STEP 2 DO
    SEND i TO DISPLAY
END FOR
 STEP is optional (default 1) and may be negative.
Fixed repeats 
REPEAT 3 TIMES
    SEND "Hello" TO DISPLAY
END REPEAT
 The count must be a whole number.
Condition first 
WHILE count < 5 DO
    SET count TO count + 1
END WHILE
 The body may run zero times.
Condition last 
REPEAT
    RECEIVE guess FROM (INTEGER) KEYBOARD
UNTIL guess = 7
 The body always runs at least once.
Each element 
FOR EACH item FROM basket DO
    SEND item TO DISPLAY
END FOREACH
 Works on arrays and on the characters of a string.

4. Subprograms

PROCEDURE greet(name)
BEGIN PROCEDURE
    SEND "Hi " & name TO DISPLAY
END PROCEDURE

FUNCTION square(n)
BEGIN FUNCTION
    RETURN n * n
END FUNCTION

greet("Ava")
SET area TO square(4)

A procedure is called on its own line and gives nothing back. A function must RETURN a value and is used inside an expression. Both can read and change variables from the main program. New variables made inside them are local.

5. Arrays and strings

SET scores TO [12, 18, 9]
SET scores[1] TO 20
FOR i FROM 0 TO LENGTH(scores) - 1 DO
    SEND scores[i] TO DISPLAY
END FOR

SET grid TO [[1, 2], [3, 4]]
SEND grid[1][0] TO DISPLAY      # 3

SET word TO "code"
SEND word[0] TO DISPLAY         # c

Indexes start at 0, so the last valid index is LENGTH(scores) - 1. In a 2D array the row comes first. Strings can be read by index but not changed one character at a time.

6. Operators

Kind Operators Notes
Arithmetic+ - * / ^/ always gives a real result. ^ is power.
Integer divisionDIV MOD7 DIV 2 is 3. 7 MOD 2 is 1.
Comparison= <> < <= > >=One = compares. <> is not equal. == and != are rejected.
LogicAND OR NOTWrite a full comparison on each side: x > 0 AND x < 10.
Text&Joins text and values: "Total: " & total.

7. Built-in functions

LENGTH(x)
Number of items in an array, or characters in a string.
RANDOM(n)
A random whole number from 0 to n inclusive.
INT(x)
Turns a number or numeric text into a whole number. Helper provided by this IDE.
STR(x)
Turns a value into text. Helper provided by this IDE.

8. Debugger

Command Key What it does
RunF5Starts from the top. Stops at the end or at a breakpoint.
StepF10Runs one line. The yellow line is the one that runs next.
ContinueF8While paused, runs to the next breakpoint or the end.
ResetShift+F5Stops the program so you can edit and start again.
BreakpointclickClick a line number to add or remove a red breakpoint dot.

Each program opens in its own editor tab. Convert to (in the toolbar and the Convert menu) translates the current program into one of the other two languages and opens the result in a new tab, so the original stays as it was. Statements with no direct equivalent, such as Python dictionaries or Cambridge record types, are kept as TODO comments for you to finish by hand.

Save and Save as use the .epc extension for this language, or plain .txt. Ctrl+S saves the current tab.

While paused, the Variables pane lists each value and its type. A value that changed on the last step is shown in red. Inside a subprogram, local variables are marked and the Call stack shows where it was called from. Syntax is checked as you type, and the first problem appears in Problems and the status bar.
