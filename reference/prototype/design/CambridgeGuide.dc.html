Cambridge pseudocode reference

What the IDE accepts for Cambridge IGCSE (0478), O Level (2210) and International AS & A Level (9618). Keywords and built-in functions are in capitals, variables are declared with a type, and assignment uses ←.

1. Variables and data types

DECLARE Total : INTEGER
DECLARE Price : REAL
DECLARE Initial : CHAR
DECLARE Name : STRING
DECLARE Found : BOOLEAN
DECLARE Today : DATE

Total ← 0
Name ← "Sam"
CONSTANT VAT ← 0.2
TypeHoldsLiteral
INTEGERWhole numbers42 -7
REALNumbers with a decimal part3.5 -0.25
CHARExactly one character'A'
STRINGText of any length"Hello"
BOOLEANTRUE or FALSETRUE
DATEA calendar dateSETDATE(25, 12, 2025)

Assign with the arrow ←. You can type <- instead; the IDE treats them the same. 0478/2210 writes constants with ←, 9618 with =, and both are accepted. Names are not case-sensitive in Cambridge pseudocode, so Total and TOTAL are the same variable, but keep one spelling. A value must match the declared type: storing 3.5 in an INTEGER is an error.

2. Input and output

OUTPUT "Enter your name"
INPUT Name
OUTPUT "Hello ", Name, ", you are ", Age
// a comment runs to the end of the line

OUTPUT prints the items you list, joined with no spaces added. When INPUT runs, the console waits for you to type a value and press Enter, then converts it to the variable's declared type. To show a prompt, OUTPUT it on the line before INPUT.

3. Selection

IF Mark >= 50
  THEN
    OUTPUT "Pass"
  ELSE
    OUTPUT "Fail"
ENDIF

IF Mark >= 70 THEN
    Grade ← 'A'
ENDIF

THEN can sit on its own line (the Cambridge layout) or at the end of the IF line. There is no ELSE IF. For more outcomes, put another IF with its own ENDIF inside the ELSE, or use CASE.

CASE OF Choice
    1 : OUTPUT "Add"
    2 : OUTPUT "Delete"
    3 TO 5 : OUTPUT "Other"
    OTHERWISE : OUTPUT "Invalid choice"
ENDCASE

Each branch is a value or a range with TO, then a colon and a statement. A branch may continue on the following lines. OTHERWISE is optional and must be last.

4. Iteration

5. Arrays

DECLARE Scores : ARRAY[1:5] OF INTEGER
Scores[1] ← 12

DECLARE Grid : ARRAY[1:3, 1:4] OF CHAR
Grid[2, 3] ← 'X'

Total ← 0
FOR i ← 1 TO 5
    Total ← Total + Scores[i]
NEXT i

The bounds are set in the DECLARE, as lower:upper. Cambridge arrays usually start at 1. A 2D array takes the row, then the column, separated by a comma. Every element starts with no value: reading one before you assign it is reported as an error, which catches loops that miss an element.

6. Procedures and functions

PROCEDURE ShowLine(Size : INTEGER, Symbol : CHAR)
    DECLARE i : INTEGER
    FOR i ← 1 TO Size
        OUTPUT Symbol
    NEXT i
ENDPROCEDURE

FUNCTION Square(N : INTEGER) RETURNS INTEGER
    RETURN N * N
ENDFUNCTION

CALL ShowLine(3, '*')
Area ← Square(4)

Run a procedure with CALL. A function states its RETURNS type, must reach a RETURN, and its result has to be used. Each parameter has a type. Variables declared inside a subroutine are local to it.

PROCEDURE Swap(BYREF X : INTEGER, Y : INTEGER)
    DECLARE Temp : INTEGER
    Temp ← X
    X ← Y
    Y ← Temp
ENDPROCEDURE

BYVAL (the default) passes a copy. BYREF passes the variable itself, so changes are seen by the caller. A BYREF or BYVAL keyword applies to every parameter after it until the other keyword appears, so both X and Y above are BYREF. The arguments for BYREF parameters must be variables.

7. Records and text files (9618)

TYPE Student
    DECLARE Name : STRING
    DECLARE Score : INTEGER
ENDTYPE

DECLARE Class : ARRAY[1:30] OF Student
Class[1].Name ← "Ama"
Class[1].Score ← 61
OPENFILE "scores.txt" FOR WRITE
WRITEFILE "scores.txt", "Ama,61"
CLOSEFILE "scores.txt"

OPENFILE "scores.txt" FOR READ
WHILE NOT EOF("scores.txt")
    READFILE "scores.txt", LineOfText
    OUTPUT LineOfText
ENDWHILE
CLOSEFILE "scores.txt"

Modes are READ, WRITE (starts an empty file) and APPEND. In this IDE files live in memory while the program runs, and each one appears in the Variables pane with its lines. Enumerated and pointer types, and random-access files, are not supported.

10. Debugger

CommandKeyWhat it does
RunF5Starts from the top. Stops at the end or at a breakpoint.
StepF10Runs one line. The yellow line is the one that runs next.
ContinueF8While paused, runs to the next breakpoint or the end.
ResetShift+F5Stops the program so you can edit and start again.
BreakpointclickClick a line number to add or remove a red breakpoint dot.

Each program opens in its own editor tab. Convert to (in the toolbar and the Convert menu) translates the current program into one of the other two languages and opens the result in a new tab, so the original stays as it was. Statements with no direct equivalent, such as Python dictionaries or Cambridge record types, are kept as TODO comments for you to finish by hand.

Save and Save as use the .cpc extension for this language, or plain .txt. Ctrl+S saves the current tab.

While paused, Variables lists each value with its declared type. Elements with no value yet show as —. A value that changed on the last step is shown in red. Inside a procedure or function, local variables are marked and the Call stack shows where it was called from.
