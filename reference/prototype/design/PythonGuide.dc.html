Python reference

The Python 3 the IDE runs, with the error messages you will see and what usually causes them. Blocks are marked by a colon and four spaces of indentation.

A variable is created the first time you assign it. Names are case-sensitive, so Score and score are different. / always gives a float, so 6 / 2 is 3.0. Use // for whole-number division.

2. Input and output

name = input("Name: ")
age = int(input("Age: "))
height = float(input("Height in m: "))

print("Hello", name)
print("Next year you will be", age + 1)
print(f"{name} is {height:.2f} m tall")
print("a", "b", sep="-", end="!\n")

input() always returns text. Convert it with int() or float() before doing maths or comparing with numbers. In the IDE, input() shows its prompt in the console and waits for you to type a value and press Enter.

3. Selection

if mark >= 70:
    grade = "A"
elif mark >= 50:
    grade = "B"
else:
    grade = "C"

if 0 <= age <= 120 and name != "":
    print("Valid")

Lines that start a block end with a colon, and the block is indented by four spaces. Compare with == and !=, combine conditions with and, or and not. Python allows chained comparisons such as 0 <= age <= 120.

5. Functions

def square(n):
    return n * n

def greet(name, greeting="Hello"):
    print(greeting, name)

area = square(4)
greet("Ava")
greet("Ben", "Hi")

A function without return gives back None. Parameters can have default values. Variables assigned inside a function are local to it.

count = 0

def add_one():
    global count
    count += 1

Without global count, the line count += 1 would make count local to the function and fail with UnboundLocalError. Passing values in and returning results is usually clearer than using global.

6. Lists and strings

scores = [12, 18, 9]
scores.append(20)        # [12, 18, 9, 20]
scores.insert(0, 5)      # [5, 12, 18, 9, 20]
scores.remove(18)        # removes the first 18
last = scores.pop()      # removes and returns 20
print(scores[0], scores[-1], len(scores))

grid = [[1, 2], [3, 4]]
print(grid[1][0])        # 3

word = "Python"

Indexes start at 0, and negative indexes count from the end. Slices [start:end] stop before end. Strings cannot be changed in place: string methods return a new string.

7. Dictionaries

ages = {"Ama": 15, "Ben": 16}
ages["Chen"] = 15
print(ages["Ama"], ages.get("Dan", 0))

for name, age in ages.items():
    print(name, age)

if "Ben" in ages:
    del ages["Ben"]

Reading a missing key with [] raises KeyError. get() returns a default instead. in checks the keys.

8. Validation with try and except

while True:
    try:
        age = int(input("Age: "))
    except ValueError:
        print("Please type a whole number")
        continue
    if 0 <= age <= 120:
        break
    print("Out of range")

The except block runs only when the matching error happens inside try. except ValueError as e: also gives you the message as e.

10. What the simulator supports

The IDE runs the parts of Python 3 used in GCSE and International GCSE courses: variables, all the control structures above, functions with default and keyword arguments, lambda, lists, tuples, dictionaries, sets, list comprehensions, f-strings, str.format and % formatting, try / except / finally, and the random, math and time modules. Whole numbers have no size limit.

Not supported: classes, with and file access, generators and yield, *args and **kwargs in definitions, and other modules. Using one of these is reported as an error on its line.

11. Debugger

CommandKeyWhat it does
RunF5Starts from the top. Stops at the end or at a breakpoint.
StepF10Runs one line. The yellow line is the one that runs next.
ContinueF8While paused, runs to the next breakpoint or the end.
ResetShift+F5Stops the program so you can edit and start again.
BreakpointclickClick a line number to add or remove a red breakpoint dot.

Each program opens in its own editor tab. Convert to (in the toolbar and the Convert menu) translates the current program into one of the other two languages and opens the result in a new tab, so the original stays as it was. Statements with no direct equivalent, such as Python dictionaries or Cambridge record types, are kept as TODO comments for you to finish by hand.

Save and Save as use the .py extension for this language, or plain .txt. Ctrl+S saves the current tab.

While paused, Variables lists each value with its Python type and repr, so text shows in quotes. Functions and imported modules are hidden. A value that changed on the last step is shown in red. Inside a function, local variables are marked and the Call stack shows the calls back to <module>.
