# Roadmap

Plans can change. Nothing in "Coming next" is promised for a date.

## Done

See [Features](FEATURES.md).

## Coming next

| Item            | What it means                                                       |
| --------------- | ------------------------------------------------------------------- |
| Desktop app     | Installers for Windows, Mac and Linux, with real files on your disk |
| Android app     | An app you can install on an Android phone or tablet                |
| More converting | More directions, for example Python to pseudocode                   |

The version history is in the project's release notes.

## Ideas (not decided)

- Code suggestions while you type. This is only an idea. It is not in any plan yet.
- Translations. The app and docs are English only. If you can help, open an [idea](https://github.com/humanspolluteearth/sudocode/issues/new?template=feature_request.yml).

## Not planned

These were looked at and left out of the first release, on purpose:

| Item                                          | Why                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------- |
| Accounts, sharing links, publishing           | Sudocode stores nothing about you. That keeps it private and simple |
| Tracking or analytics                         | Same reason                                                         |
| AI help                                       | The goal is for you to think it through yourself                    |
| Python `turtle` drawing                       | Not in the two courses Sudocode is built for                        |
| Edexcel records, Cambridge pointers and sets  | Not needed for the first release. We may add them if students ask   |
| Extra helper functions the exam does not have | Sudocode follows the official command set                           |

The reasons for these choices are in the [decisions log](DECISIONS.md) and the [language spec](language-spec/README.md).
