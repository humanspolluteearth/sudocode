# Error messages harvested from the prototype

Every error message and hint in the prototype's three interpreters, for the M1 message catalogue
(`packages/core/src/messages/`). Source: `reference/prototype/harness/engines.cjs` (the "Line" column), which is
the prototype's `prototype-main.js` cut into a Node module. Harvested 23 Nov 2026 by parsing the file and listing
every call to its error helpers (`err`, `syn`) plus the wrong-language hint tables (`STMT_HINTS`, `OTHER_LANG`).

How to read the tables:

- `{name}` is a value the prototype filled in at run time (a variable name, a type, a line number...).
- Rows from the hint tables show the message the prototype printed with them (lines 139 and 715).
- `(a | b)` means the prototype chose between two wordings, `a` when its condition held and `b` otherwise.
- **Note for M1** flags messages whose behaviour no longer matches the approved spec (`docs/language-spec/`), so they
  must be reworded or dropped rather than copied. A blank note means the message still fits the spec.

What to keep when building the catalogue:

- The tone: short, plain words, one idea per message, and a hint that shows the correct form (for example
  "Use <> for "not equal to"", "Write SET x TO <value>", "Did you mean ...?"). This matches SH-15.
- The wrong-language hints (a student types `PRINT` in Edexcel or `SEND` in Cambridge): they are excellent.
- Every message gets a code, a line and a column (SH-15). The prototype has line numbers only.

What changes:

- Lenient forms (SH-16) are warnings now, not errors: lowercase keywords (EDX-05, CIE-02), `ENDIF` (EDX-44),
  `ELSE IF` (EDX-42, CIE-51), `FOREACH` (EDX-58), double-quoted Edexcel strings (EDX-07).
- No output cap (the prototype stopped at 5,000 lines). Possible infinite loops pause after 10 million steps (SH-14).
- The recursion limit is 1,000 and the message names the procedure (SH-13).
- "this simulator" becomes "Sudocode"; unsupported constructs use the SH-18 wording "not supported in Sudocode yet".
- Python messages must keep CPython's exception name and, where CPython prints one, CPython's exact message
  (PY-01, PY-03); Sudocode adds its hint after it.
- Many pseudocode runtime type errors become checker errors before the program runs (EDX-12, CIE-13, CIE-45).
