# UI-3 review notes

- Tablet side panel: the tablet layout hides the menu bar, so the View > Side panel entry (ticked while shown) is
  only visible where a menu bar shows. The toggle button at the right of the toolbar is the working control on tablets.
- A pause (not `stepLimit`) or an error while the panel is hidden lights a red dot on the toggle and an
  screen-reader message; it never reopens the panel. Showing the panel clears the dot.
- Nothing failed twice.
