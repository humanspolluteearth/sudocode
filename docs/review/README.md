# Milestone reviews

Claude writes `Mxx.md` at the end of each milestone; you read it before starting the next one.
Your answers go in `QUESTIONS.md`.

## Template for Mxx.md
```markdown
# Mxx review

## Summary
What was built, in 5 lines. PRs: #.., #..

## Expected answers to check
| Spec ID | File | Expected (short) |
|---|---|---|

## Decisions made without you
| Decision | Why | Spec/decision it follows |
|---|---|---|

## Questions for you
1. ... (tests affected: ..., currently pending)

## Required checks to add to the ruleset
- ...

## Known gaps and pending tests
| Test ID | Reason |
|---|---|

## Try it
Preview link, and 3 things worth trying by hand.
```
