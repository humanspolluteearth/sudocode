# M2 review

## Summary

M2 makes Edexcel pseudocode run end to end:

- **Shared back end (#24):** the core IR, and a pausable runtime with a trampolined call stack.
- **Edexcel front end:** the lexer (#25), the parser (#27), and the checker, lowering and engine (#28).
- **Tests (#23):** 194 new golden programs: conformance (one or more per spec row), error wording (one per diagnostic code and variant) and five whole programs.
- **CI (#26):** a nightly workflow.
- **Results:**
  - 214 of the 227 Edexcel programs pass. The rest are features after M2 (input, subprograms, files, 2D arrays) or wait on your answers (Q20, Q26).
  - All 57 in-scope spec IDs have a passing test: 62 of 210 overall.
  - SH-13's 1,000-deep recursion runs inside a worker thread with a 1 MB stack, and 100,000-deep with the limit raised.

PRs: #21 your answers 14-19, #23 tests, #24 core IR and runtime, #25 lexer, #26 nightly workflow, #27 parser,
#28 checker, lowering and engine, plus the review follow-ups and this review (see the PR list).

Question 32 (a merged M0 check blocked the engine PR) was answered "yes" and #28 merged with CI green. The only
wrinkle: the new check must accept answers written as `- Answer (date): ...`, which Q7 uses, so it matches
`- Answer[^:]*:`; otherwise EDX-05's probe would have stayed wrongly pending.

## Try it

There is no UI for running code yet (M3). From the repo root:

1. `pnpm test`: about 2,470 tests, including every Edexcel golden program running through the same Runner the UI will use.
2. Run your own program:
   `node --input-type=module -e 'const {runHeadless}=await import("./packages/core/src/runner/headless.ts");const {createLocalRunner,ENGINES}=await import("./packages/core/src/engine.ts");const r=await runHeadless(createLocalRunner(ENGINES),{language:"edexcel",source:"SET x TO 7 / 2\nSEND \"x is \" & x TO DISPLAY\n",files:{},seed:1,breakpoints:[],trace:false},[]);console.log(r.stdout,r.warnings.map(w=>w.message))'`
   Try a typo, a missing END IF, or `x = 5` to see the messages.
3. `pnpm spec:coverage`: the table now shows which spec rows are proven.
