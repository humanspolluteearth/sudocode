## Design (compiler concepts in the PR description)

Third front end: lexer with INDENT/DEDENT, recursive descent plus Pratt parser, scope resolution at lowering time (global/local/free + hops), closures through a hidden `$closure` parameter, all lowering to the shared IR (`pyArith floordiv`, `pyCompare` chains). The runtime is shared, not forked. Python ints are BigInt; exceptions are `RunError` with `E-PY-<Name>`.

## Differences and choices to check

- `keys()`, `values()`, `items()` return lists; `map` and `filter` are eager lists.
- Comprehension variables are hidden `$` variables, so a lambda or def inside a comprehension that captures the loop variable does not resolve it.
- No `%` formatting. Shifts and `~` are unsupported; `| & ^` work for ints and sets. Set order is emulated for int sets only.
- `math`, `random`, `datetime`, `time`, classes and `with` are "not supported" until M9. `PY-41-example-guessing-game` stays pending for that reason. Bytes are unsupported.
- PY-04: undefined-name and argument-count errors are found at run time with CPython's message, not before running.
- The debugger shows the `pyStr` text of values.
- The 8 harvested Python tests pass under CPython 3.12.
