- **CI (#42-#44):** `build-web` with a size budget, `test-ui`, `e2e-chromium`; Cloudflare preview/staging workflow; nightly Firefox and WebKit (a manual run passed).
- **Review fixes:** PR "fix: M3 review findings" (architecture and test reviewers; every MUST FIX fixed).
