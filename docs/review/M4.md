## Review results

**Architecture reviewer:** no MUST FIX. SHOULD FIX:

- `stepInto`/`stepOut` already exist in the protocol and driver (M5 scope). Kept on purpose: the driver's depth
  rule covers all four commands in one table, and the UI only offers Step over.
- `packages/core/src/edexcel/parser.ts` is 415 lines (limit about 400). Left for an M5 split by statement kind.
- Settings and Simple mode switches for the debugger: these arrive in M10 (`docs/milestones/M10`), so the
  debugger is always on for now.
- Touch targets: fixed in #51 with a `@media (pointer: coarse)` block (44x44 buttons, wider gutter).

**Test reviewer:** two MUST FIX items, both fixed with new tests rather than by editing merged ones:

1. The SH-14 test didn't prove that Continue resets the budget. New test "SH-14 Continue after the step limit
   gives the program another full budget of steps" (fails if the reset is removed; checked by mutation).
2. No test that Pause stops _inside_ a running loop. New test "MISC Pause sent while a loop runs stops inside the
   loop, with the variables as they are there".

SHOULD FIX done: SH-07 input boundaries; it.each tables of accepted and rejected input lines (D1/D2/D11);
CHARACTER input not trimmed and emoji; run-state reset on Run; E2E asserts exact values and the exact trace;
input-box Enter on an empty line; Cancel/Escape ends the program (new Cancel button, SH-05); EDX-74 prompt label.

## Try it

On #51's branch (`git switch feat/m4-ui-debugger && pnpm dev`):

1. Type `SET total TO 0` / `FOR i FROM 1 TO 2 DO` / `    SET total TO total + i` / `END FOR` /
   `SEND total TO DISPLAY`.
2. Click the gutter left of line 3 (or put the cursor there and press F9), then Run (F5). The run stops on line 3,
   which is highlighted; Variables shows total 0, i 1. Continue (F5) and the changed values are marked.
3. Open the Debugger tab before Run to get the trace table (one row per assignment and output line).
4. Try `RECEIVE n FROM (INTEGER) KEYBOARD`: the console asks for a line; type `abc` to see the SH-06 error, or
   press Escape to end the program.
5. `WHILE TRUE DO` / `END WHILE` pauses after 10 million steps with a Continue/Stop dialog.
