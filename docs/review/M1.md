# M1 review

## Summary

M1 built the skeleton every later milestone plugs into:

- **Packages:** `packages/ui` (React) and `apps/web` (a Vite shell rendering "Sudocode") join `packages/core`, with dependencies enforced by lint as apps → ui → core.
- **Core types:** `Diagnostic` and `Span`, the plain-data UI–engine protocol (`Runner` plus every worker message), and a message catalogue of 64 codes with per-language wording.
- **Workers:** a run worker and a check worker around an engine-neutral Runner, which says "can't run this language yet".
- **Golden runner:** runs every `.expected.json` program through that Runner and enforces `pending.json`.
- **Coverage:** `pnpm spec:coverage` and a CI job with the table in the job summary.

Your answers Q1, Q4, Q5 and Q9 are applied first (spec rows plus three corrected expected files). On `main`, `pnpm check` passes with 1057 tests; spec coverage is an honest 0 of 210, since no language exists yet.

PRs (all squash-merged with CI green): #11 answers and corrections, #12 diagnostics and protocol, #13 message catalogue, #14 workers and Runner, #15 golden runner, #16 spec coverage, #17 ui and web, #18 test-review follow-ups, #19 architecture-review follow-ups, #20 this review.
